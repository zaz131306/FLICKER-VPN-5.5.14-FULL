⚡ FLICKER VPN Pro — Настройки

📡 Подписки (автопоиск серверов)

Расширение скачивает бесплатные подписки Hysteria 2, парсит ссылки hysteria2:// и проверяет каждый узел в три этапа: TCP → QUIC prescan → HTTP через туннель (gstatic 204 + cloudflare 200). В списке остаются только живые; задержка — реальная, медиана проб через туннель.

URL подписки (можно несколько)

По одному URL в строке. Формат: plain-текст или base64 со ссылками hysteria2:// / hy2://.

Источник: встроенные (RU-списки ежечасно, мировые агрегаторы раз в 6–24 ч) + свои + производные из мета-источника. Раз в 10 минут допроверяются только новые и протухшие ноды — доверенные не прозваниваются.
